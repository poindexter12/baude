<objective>
**Idle performance gates, process-identity-safe suspension, and daemon parity:** Implement metadata polling gates so archived/exited rows are never touched, apply mtime checks to unchanged files with per-source cache invalidation rules, add identity-verified suspension/resume (verify ProcessIdentity before SIGSTOP to prevent sending signals to wrong process groups), extend idle child policy to the daemon (archive/unarchive endpoints apply the same policy), and make the usage poller optional via config.

**Purpose:** Per-session polling that touches every session regardless of archive state scales CPU cost with session count. Polling ~100 idle sessions every 1 second costs ~100 stats + 100 reads per second. Mtime gates reduce reads to zero when no sessions change. Idle child suspension saves CPU and battery by pausing unused children. PID reuse is a critical hazard (session.rs:641,655 already verify identity before signal); suspend/resume must do the same. Daemon parity ensures idle child policy applies consistently to remote archive operations. Optional usage poller respects user preferences.

**Output:** Metadata polling gates (skip archived/exited, mtime check with per-source cache rules), identity-verified suspend/resume via SIGSTOP/SIGCONT, daemon archive/unarchive endpoints applying idle child policy, and conditional usage poller thread spawn.
</objective>
