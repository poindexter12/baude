# Phase 22.1 Plan 02: Test leftover check Summary

`scripts/assert-no-test-leftovers.sh` runs a test command with a fixture TMPDIR and samples the process table beside it. It fails on `baude-*`/`bauded-*` entries left behind, on non-descendant processes still working under the dir across the persist window, and on any process still working there at the end. It catches HEAD's `kill_reaps_live_child` stray `sleep 30`.

## What was built

- `run <dir> -- <command...>`: refuses with exit 2 when realpath(dir) lies inside a git work tree, or when the dir already holds a fixture entry. Otherwise it creates the dir and sets `TMPDIR` to the dir exactly as given. The sampling thread starts before the command and stops after it. Then the end check runs: live processes plus fixture entries.
- `check <dir>`: end check alone, `command=-`.
- `--self-test`: 16 checks with synthetic cases only. They cover the six fixture-entry behaviours, the stale-entry refusal, and the four process cases (orphan, descendant, live, deleted working folder), plus the path-form note.
- Process readers: Linux takes ppid from `/proc/<pid>/stat` after the last `)`, and cwd from `/proc/<pid>/cwd` with ` (deleted)` stripped. macOS uses `lsof -nP -w -d cwd -Fpn`, ignoring its exit when output parsed and exiting 2 when lsof is missing, plus `ps -axo pid=,ppid=,command=`. Helpers run from `/` so their own cwd never lands under the dir.
- Summary line: `assert-no-test-leftovers: command=<rc> orphans=<n> live=<n> dirs=<n>` on stdout. Details go to stderr.

- **Fix:** The orphan and descendant cases now wait 9 s, with the orphan `sleep 15` killed by pid. Three consecutive macOS runs and the Docker run all pass. The macOS self-test now takes about 30 s, still under the plan's 60 s.
- **Files modified:** scripts/assert-no-test-leftovers.sh
- **Commit:** d23bb2c

- **Found during:** Task 2 bite checks

- **Fix:** The deleted-folder case also asserts that stderr names `cwd=<realpath>/w4 command=`. That is lsof's reported path on macOS and the stripped link on Linux. The mutation now fails it.
- **Commit:** 31d73ef

## Open Items

- Production sampling period is the 2 s interval plus lsof and ps time, about 2.3 to 4 s on this macOS host. A 30 s `sleep 30` leak is still seen many times. Plan 22.1-06 should keep the defaults unless a gate run shows otherwise.
