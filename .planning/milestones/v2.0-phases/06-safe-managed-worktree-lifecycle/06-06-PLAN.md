<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| confirmation → destructive mutation | Human intent does not freeze Git state; authorization must be refreshed. |
| stopped runtime → second Git preflight | Agent/external processes may have changed files or topology before stop. |
| Git commit → durable JSON commit | Topology and persistence cannot be one atomic transaction. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-12 | Tampering / Information loss | confirmed remove TOCTOU | mitigate | Per-repository reservation, stop-before-second-preflight, fresh inspection, and Git's plain non-force safeguard. |
| T-06-13 | Elevation / Information loss | removal authorization/UI | mitigate | Managed linked ownership token, distinct target-naming confirmation, cancel/no-op tests, and no direct UI Git calls. |
| T-06-14 | Tampering / Repudiation / DoS | runtime/Git/persistence commit boundaries | mitigate | Pre-Git runtime compensation, exact postconditions, commit-stage outcomes, unavailable recovery context, and no automatic recreation. |
</threat_model>
