Implement WORK-03 as a retained close transaction shared by App and Manager: snapshot full context, durably deactivate, then stop one runtime without deleting checkout or repository identity.

Purpose: Make close non-destructive and ensure a persistence failure cannot strand or forget a live coding-agent conversation.
Output: Compatible retained resume metadata, shared close semantics, and commit-aware owner adapters.
</objective>

- Backward-compatible opaque targeted-resume metadata in each retained child.
- Save-before-stop close transition preserving checkout, branch, parent, ordering, and user settings.
- App and Manager close behavior with pre/post-replacement failure semantics.
