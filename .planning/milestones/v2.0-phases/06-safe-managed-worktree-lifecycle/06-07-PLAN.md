<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted bytes → lifecycle authority | Malformed or contradictory state must not authorize launch/destruction. |
| lifecycle request → core engine | Adapters may request but cannot select/reorder transitions or effects. |
| persisted candidate → Git/process effect | Durable write-ahead evidence authorizes external mutation. |
| PID/runtime map → OS process group | Reused identifiers and dropped handles cannot grant or erase ownership. |
