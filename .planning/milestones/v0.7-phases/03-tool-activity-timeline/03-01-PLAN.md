<objective>
Add a capped per-session tool-activity ring buffer to `baude-core` (ACT-01). Introduce the one new typed struct of this phase — `HookEvent {event, tool?, notification_type?, ts}` (the first serde-`Serialize` type produced by `ClaudeMeta`, explicitly sanctioned by CONTEXT) — and an `activity: VecDeque<HookEvent>` field on `ClaudeMeta` that `read_event_tail` appends to inside its existing parse loop, drop-oldest capped at `ACTIVITY_CAP` (~200), and cleared on event-path rotation.

Purpose: This ring is the single source of truth for the activity timeline. Both the TUI-local path (reads `s.meta` directly) and the daemon (holds `ClaudeMeta`, so it serves the ring "for free") derive their views from this one buffer — no mirrored second buffer to keep in sync.

Output: `HookEvent` struct, `ACTIVITY_CAP` const, `ClaudeMeta.activity` field, `activity()` accessor, ring append + cap + rotation-reset, and the unit tests proving cap/drop/clear/serde.
</objective>
