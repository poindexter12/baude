<objective>
Add the per-deploy `BAUDE_PERMISSION_MODE = skip | prompt` switch (default `skip`) that selects exactly one permission flag for the spawned `claude` command, and — in `prompt` mode only — seeds a non-clobbering `.mcp.json` registering the `permission-mcp` stdio server. This is PERM-01: the security-critical default-stays-skip gate.

Purpose: `skip` preserves today's unattended `--dangerously-skip-permissions` behavior; `prompt` is strictly opt-in and routes tool-permission decisions to baude via `--permission-prompt-tool mcp__baude__approve`. A regression making `prompt` the default would block overnight runs — a high-severity finding (project non-negotiable, D-permission-mode).

Output: a new pure `baude-core/src/permission.rs` module with `permission_flag(base_cmd)` and an `.mcp.json` config builder, wired into both spawn sites (`bauded/src/manager.rs::spawn_command`/`spawn`, `baude/src/app.rs::claude_cmd`).
</objective>
