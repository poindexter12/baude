<objective>
Build the `prompt`-mode transport: a hand-rolled stdio JSON-RPC MCP server (`permission-mcp` subcommand in BOTH binaries) that Claude invokes for unresolved tool calls, the daemon-side `pending_permission` state on `Session` (Manager set/resolve, awaited OUTSIDE the lock), and the `GET`/`POST /sessions/{id}/permission` REST routes. This is PERM-01's transport half + PERM-02.

The single MEDIUM-confidence unknown — the exact Claude Code `--permission-prompt-tool` wire contract (request field names + MCP response wrapping, RESEARCH §C/§D/§F) — is gated by a mandatory `checkpoint:human-verify` CONTRACT UAT that runs a raw-frame-logging `permission-mcp` against live `claude` 2.1.178 BEFORE the prompt-mode bridge is finalized.

Purpose: route each unresolved tool-permission decision through baude with **deny-on-timeout, never auto-allow** (security-critical, V4). The bridge process blocks on Claude's critical path (unlike the always-exit-0 hook); the daemon must NOT hold the manager lock across the human wait (Pitfall 4).

Output: `baude_core::permission` JSON-RPC framing + result builders; `permission-mcp` arms in `baude/src/main.rs` and `bauded/src/main.rs`; `Manager` pending-state set/resolve; two REST handlers + route.
</objective>
