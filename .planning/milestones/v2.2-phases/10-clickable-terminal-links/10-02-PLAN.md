<feature>
  <name>Per-cell link fidelity through grid operations and formatted-output round-trip</name>
  <files>vendor/vt100/src/{screen.rs,attrs.rs,cell.rs,grid.rs}, fork link_ test module, baude-core/src/pty.rs (tests)</files>
  <behavior>
    Cases (parser bytes in -> Screen state out):
    - open link, print past bottom row -> scrolled-to-scrollback cells retain link id; `set_scrollback` view resolves the same target
    - open link, label wraps -> both fragments share one id (regression from 10-01)
    - open link, resize smaller/larger -> surviving cells keep ids; no panic
    - overwrite a linked cell with plain text -> its link id is gone
    - open link then `\e[2J` (and `\e[K` line erase) -> NO cell reports a link id (Pitfall 4 — guaranteed-RED target)
    - URI of 3000 bytes -> link is None; parse continues (Pitfall 6 — guaranteed-RED target)
    - intern table at cap -> further new (id, uri) pairs get None; existing ids still resolve
    - `\e]8;;https://ex.com/a;b;c\e\\` -> target is the full 2-semicolon URI (rejoin regression)
    - empty-URI close: text after `\e]8;;\e\\` carries no id
    - round-trip: parser A processes linked output -> contents_formatted() -> fresh parser B -> B reports identical link ids/targets per cell (Pitfall 3 — guaranteed-RED target: stock writer emits SGR only)
    - baude-core pty test: build the snapshot exactly as subscribe() does (alternate-screen preamble + contents_formatted, pty.rs:390-410) -> feed to a fresh parser -> link targets identical (remote pre-attach parity)
  </behavior>
  <implementation>
    Erase-strip: at every Cell::clear/fill call site (cell.rs `clear(attrs)` and its
    grid.rs/row.rs callers), pass attrs with `link: None` — a cleared cell must never
    inherit the current drawing link. Caps: in intern_link, refuse URIs > 2083 bytes
    and new entries past the cap (recommend 10_000; u16 index space) by returning
    None. Re-emission: in the formatted-output writer (grid.rs
    write_contents_formatted and the diff writer if it shares the path), when the
    cursor crosses a cell whose link id differs from the previous cell's, emit
    `\x1b]8;;URI\x1b\\` (open) or the empty-URI close when leaving a link; preserve
    the id= param if present. Keep the diff surface minimal and record any new file
    touched in vendor/vt100/README.md's diff-surface list.
  </implementation>
</feature>
