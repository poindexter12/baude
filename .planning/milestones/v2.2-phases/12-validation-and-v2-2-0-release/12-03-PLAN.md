    A title naming the phase and the release under test. Then one `## Session:` block per operating-system and terminal pair — create two, macOS and Linux — each opening with a provenance header of exactly these five lines, in this order, so the gates in Task 2 can find them:

    - `**Commit:** <sha> (clean|dirty)`

    Then a 12-leg table with exactly these six columns and this header row, because Task 3's completeness gate reads columns 5 and 6 positionally:

    `| # | Leg | What to do | What to look for | Observed (verbatim) | Result |`

    The legs, in an order that walks the session from links through input to teardown: (1) links detect — emit an OSC 8 link and a bare URL, press the hint chord, expect the overlay with its title and footer; (2) links preview — move through the list, each row shows the actual destination rather than the label; (3) links copy — the copy gesture puts the full URL on the clipboard and reports honestly on failure; (4) links open — activation launches the opener, a failed opener surfaces and the session stays alive; (5) selection — plain drag is consumed by baude, drag with the terminal's override modifier selects natively; (6) scrollback — the wheel scrolls inside the pane, and after quitting the host terminal's scrollback is unpolluted; (7) mouse — wheel, click, and drag in both the sidebar and the pane, with no stray escape bytes reaching the child and no visual corruption; (8) Shift+Enter — a newline is inserted and nothing submits; (9) ordinary Enter — submits, unchanged; (10) restoration on normal exit — the prompt returns with echo on, mouse reporting off, and no leftover control bytes; (11) restoration on an interrupt or forced-kill path — same, confirmed by running a bare command afterwards; (12) alternate-screen residue — after exit, the pre-baude terminal content is intact.

    Leave every **Observed (verbatim)** cell empty and every **Result** cell as an unmarked choice of pass, fail, or n/a. Do not pre-judge a single leg — that is the prohibition this whole artifact exists to enforce.

    Close each session block with a `### Honest gaps and deferrals` heading and a one-line format example showing the required shape: the leg number and OS, the word DEFERRED, the reason, and `Signed off by <name> on <YYYY-MM-DD>`.
