<objective>
Close the process/thread escape boundary that thread-local root redirects cannot cover.
Ordinary App fixtures must never run ccusage over developer transcripts, and even a harmless
PTY command must not first execute the developer's login shell configuration.

Purpose: App::new currently starts UsagePoller unconditionally; its detached thread runs
ccusage with inherited environment. The PTY launcher also invokes the inherited SHELL with
-il. Resolver guards and a no-write observer cannot detect these reads.
Output: inert App background services under cfg(test), contained test PTY launches, and
synthetic regressions including the UI ownership tests authored by plan 03. No production
polling, shell behavior, hook-seeding policy or CLI design changes.
</objective>
