Output: An extended `build_bridge()` writer (factored out of `run()` so it is unit-testable without stdin), the six new fields, the `schema: 2` stamp, and a net-new `#[cfg(test)] mod tests` covering full/minimal/snake-camel payloads and the schema value.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Code statusLine stdin → bridge.rs | Claude Code (trusted local process in the managed session) pipes a JSON payload to `baude statusline` on stdin. Treated as untrusted-ish input parsed via `serde_json`. |
| bridge.rs → /tmp/baude-usage-<sid>.json | The bridge writes the captured superset to a world-readable temp file keyed by session_id. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Denial of Service | Malformed/oversized payload on stdin | accept | `serde_json::from_str` is bounded by the already-read input string; parse failure falls through to `--wrap` delegation (best-effort). Writer is Claude Code, a trusted local process. Pre-existing read-to-string behavior unchanged; no new unbounded reads introduced. |
| T-01-02 | Tampering | Untrusted field content (e.g. ANSI escapes in pr.url / model) persisted to the bridge file | accept | This plan only writes the strings to a JSON file via `serde_json` (escaped, not interpreted). No rendering happens here (overlay is Plan 03, which uses ratatui Span/Line text rendering — escapes not interpreted). No `print!` of payload strings. |
| T-01-03 | Tampering | Path injection via session_id into bridge_path → /tmp/baude-usage-<sid>.json | accept | Pre-existing and unchanged by this phase; `session_id` comes from a trusted local Claude process. `bridge_path` interpolation is not modified here. Out of scope for STL-01/02 (RESEARCH Security Domain). No high-severity threat introduced. |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | No new dependencies — Cargo.toml is not modified. RESEARCH Package Legitimacy Audit: N/A (zero external packages). If a task proposes adding a crate, treat as a red flag and stop. |

No `high`-severity threats are introduced by this plan (security_block_on: high).
