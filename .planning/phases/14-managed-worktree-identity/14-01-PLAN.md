<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Marker file write/read | Untrusted or corrupted .baude-marker.json could lead to incorrect ownership claims. File is written atomically inside the managed directory with exclusive create_dir claim. |
| Marker file path resolution | Symlink-based attacks: marker file itself could be a symlink; O_NOFOLLOW rejects symlinks. Parent directory canonicalization is insufficient. |
| Canonical common dir storage | Raw bytes must round-trip losslessly (non-UTF-8 paths valid on Unix); stored as base64 in JSON. |
| Marker JSON deserialization | Unbounded input size could cause memory exhaustion or parse failures; bounded read to 1 KiB maximum. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-01 | Tampering | Marker symlink attack | high | mitigate | Use `std::fs::File::open(..., O_NOFOLLOW)` to reject symlinks; check is non-canonicalization and platform-native. |
| T-14-02 | Tampering | Marker JSON deserialization | medium | mitigate | Bounded read max 1 KiB before parsing; treat malformed marker as "ownership unknown", not fatal. Use `#[serde(deny_unknown_fields)]`. |
| T-14-03 | Tampering | Temp file ownership during write | medium | mitigate | Temp file created inside already-owned directory (post-create_dir) with unique PID suffix; atomic rename ensures no window for race. |

| T-14-06 | Denial of Service | Marker read bounded | low | mitigate | Bounded read to 1 KiB; no unbounded allocation or infinite loop on malformed JSON. |
