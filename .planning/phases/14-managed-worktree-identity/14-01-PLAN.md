## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-01 | Tampering | Marker file path | high | mitigate | Use `Path::canonicalize()` before reading marker. Reject relative symlinks (atomic rename ensures temp and dest are on same filesystem). |
| T-14-02 | Tampering | Marker JSON deserialization | medium | mitigate | Wrap read in serde Result; treat malformed marker as "ownership unknown" and move on (fail-closed). Use `#[serde(deny_unknown_fields)]`. |
| T-14-03 | Elevation of Privilege | Marker write permissions | medium | accept | Marker lives inside worktree dir under ~/.local/share/baude/; inherits parent directory permissions. Single-user, non-networked scope. |
| T-14-04 | Information Disclosure | Canonical dir paths in error logs | medium | mitigate | Log canonical dirs only in debug output or `/info` response, never in user-facing status text beyond "repository-<digest>" display. |
| T-14-05 | Denial of Service | Marker file too large | low | accept | JSON is small (< 200 bytes); serde will deserialize or error cleanly. No unbounded allocation. |
