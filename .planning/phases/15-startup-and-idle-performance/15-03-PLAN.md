<objective>
**Idle performance gates and child process lifecycle management:** Implement metadata polling gates so archived/exited rows are never touched, apply mtime checks to unchanged files, add configurable idle child suspension/termination, and make the usage poller optional via config. Remote snapshot changes only mark dirty when meaningful changes occur (not every tick).

**Purpose:** Per-session polling that touches every session regardless of archive state scales CPU cost with session count. Polling ~100 idle sessions every 1 second costs ~100 stats + 100 reads per second. Mtime gates reduce reads to zero when no sessions change. Idle child suspension saves CPU and battery by pausing unused children. Optional usage poller respects user preferences.

**Output:** Metadata polling gates (skip archived/exited, mtime check), idle child policy dispatch (keep|suspend|stop), process suspension via SIGSTOP/SIGCONT, and conditional usage poller thread spawn.
</objective>
