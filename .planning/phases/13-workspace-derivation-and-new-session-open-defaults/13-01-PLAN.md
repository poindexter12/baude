|----------|-------------|
| Launch dir → Workspace resolution | Untrusted launch dir canonicalized at startup; workspace derivation applies only for git repositories and sanitizes folder names |
| Repository root → State file path | Derived workspace names passed through sanitize() before use in state file paths |
| Folder-workspaces.json read/write | File in config dir (same permissions as breadcrumbs); advisory lock prevents concurrent corruption |
