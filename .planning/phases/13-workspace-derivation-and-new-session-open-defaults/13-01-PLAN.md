    Create `pub fn start_workspace(launch_dir: &Path, config: &Config, env: StartEnv, lock_base: &str) -> Result<StartedWorkspace, StartError>` where:
    - `StartEnv` is a struct with `ws_env: Option<String>, backend_env: Option<String>`
    - `StartedWorkspace` is a struct containing: `workspace: &'static Workspace, repo_root: Option<PathBuf>`
    - `StartError` is an enum with variants `LockHeld { diag: String }` and `LockIo { path: PathBuf, detail: String }`
    - Caller supplies `lock_base: &str` — TUI passes `"state"`, daemon passes `"daemon-state"` (from manager::STATE_BASE)
    - Steps (executed in order):
      1. Validate launch_dir is canonical (or call canonicalize internally if needed)
      2. Call `folder_workspace::plan_launch(config.folder_context_enabled(), ws_env.as_deref(), backend_env.as_deref(), Some(&memory_root), &launch_dir)` where memory_root = persist::config_dir()
      3. Extract plan.hint and plan.repo_root, clone both for later use
      4. Call `workspace::initialize_with_context(config, WorkspaceLaunchContext { hint: plan.hint, repo_root: plan.repo_root.clone() })` to cache workspace to ACTIVE
      5. Call `persist::claim_workspace_state_lock(lock_base, &ws)` to claim the workspace lock
         - If `Ok(())`: lock acquired, proceed to step 6
         - If `Err(StateLockError::Held { holder, ... })`: return `Err(StartError::LockHeld { diag: "workspace {name} is already open in another baude (pid {holder})" })` — caller MUST exit with code 1 and print the diagnostic (replicate TUI's #71 handling)
         - If `Err(StateLockError::Io { ... })`: return `Err(StartError::LockIo { path, detail: error message })` — caller handles; binding is NOT recorded on either Held or Io
      6. (Always, lock succeeded) Record derived binding if repo_root present: `if let Some(repo_root) = plan.repo_root { folder_workspace::record(Some(&memory_root), repo_root, &ws.name, baude_core::pty::now_ms()); }`
      7. Return `Ok(StartedWorkspace { workspace: ws, repo_root: plan.repo_root })`
    - Lock claim failure (Held or Io) MUST return error; caller is responsible for exit behavior (not the helper). This preserves the TUI's validated single-writer invariant from #71: refusal never leaves a half-written binding.
    - **Critical policy**: The lock is claimed and held by the process for its entire lifetime. Same-process re-acquisition (hold_state_lock) succeeds idempotently at global::HELD_STATE_LOCKS, so the lock object itself is not returned; lock is managed globally and does not drop until the process exits.
