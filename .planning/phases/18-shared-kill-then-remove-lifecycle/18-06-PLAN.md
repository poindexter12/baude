<objective>
Prove the per-row-kind rules end to end on the topology real users have (a cloned repository with a working branch on its main checkout, a managed default worktree on `main`, and a managed branch worktree) and on a `git init` repository, through the full `removal::remove` operation. ROADMAP SC3 requires tests on both fixture kinds for each rule, and CONTEXT requires a test for each never-delete rule.

Purpose: plans 02 and 04 proved the primitives on `git init` fixtures; this plan proves the composed operation on cloned fixtures and adds the keep-rule and already-removed cases the earlier plans did not exercise.
Output: a reusable `cloned_topology` helper in `testing.rs` (new, leaving lifecycle.rs's private copy untouched) and seven tests in `removal::tests`.
</objective>
