<objective>
Add the force removal primitive for managed worktree directories to `baude-core/src/git.rs`, beside `remove_verified_worktree`, so plan 04's disk stage has one call that enforces managed-root containment, runs `git worktree remove --force --force -- <path>`, falls back to delete-plus-prune inside the managed root, and proves its postcondition from `git worktree list`.

Purpose: D-RMV-01 says explicit removal bypasses the clean-tree preflight and a runtime holding the tree as cwd does not block it; D-RMV-07 says no branch is ever deleted; the CONTEXT disk rule says the fallback may delete only inside baude's managed worktree root. The private postcondition helpers live in `git.rs`, so the primitive must too (RESEARCH Pattern 3). Inputs and outputs are crisp (path in or out of root, git accepts or refuses, directory present or missing), so this is a TDD feature.
Output: `remove_managed_worktree_forced` plus its result and error types and six fixture-backed tests in `git::tests::forced_removal`.
</objective>
