<objective>
Generalize the single-row `RepositoryState::remove_standalone_session` into a batch `remove_rows` that removes checkouts, repositories and standalone sessions by key in one call and returns the removed rows for the report. This is the aggregate-side half of the identity-model generalization: one mutation covers all four row kinds so plan 04 can clone, mutate, validate and save in one statement.

Purpose: D-RMV-06 requires one atomic save per removed row set and SC5 forbids a parent without children or a child without its parent. `validate()` catches a dangling child but permits a childless parent, so the only safe shape is a batch removal of the whole set followed by `validate()` (RESEARCH Pitfall 5). Pure data transformation with explicit I/O: TDD.
Output: `RemovedRows` and `RepositoryState::remove_rows` with four unit tests in `repository::tests`.
</objective>
