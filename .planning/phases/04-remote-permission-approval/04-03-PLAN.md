<objective>
Add the `waiting_reason` enum `{permission, input, none}` to `SessionInfo` (and mirror it on `RemoteInfo`), derived from the already-captured `last_notification`, and fire a **distinct permission push** via a separate `notified_permission` set in the `Notifier` — re-armed when the permission resolves. This is PERM-04.

Purpose: the phone should learn a *permission* is pending (distinct from generic "waiting") with a push describing the action ("wants to run X — approve?"). `waiting_reason` is the signal the PWA card (04-04) and the push both key off.

Output: a pure `waiting_reason` mapper in `baude_core::permission`; `SessionInfo.waiting_reason` populated in `session_info()`; the distinct push + re-arm in `notify.rs` (plus the recurring `#[cfg(test)] fn info()` constructor fix); `RemoteInfo.waiting_reason` mirror.
</objective>
