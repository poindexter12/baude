<objective>
Consume the hook event stream and derive authoritative session state from it. Add an offset-tracked `read_event_tail` to `meta.rs` (mirroring `read_transcript_tail`) that maps events to a new `hook_status` field and records `last_tool` + `notification_type`, then layer a higher-precedence hook branch into `session.rs::status()` behind a `StateSource` label while leaving the silence fallback byte-identical.

Purpose: This is the heart of HOOK-02 — working/waiting/done now comes from Claude hooks, not PTY silence, with the silence path preserved as a labeled fallback (no v0.6.1 regression). Plan 01 produced the event lines; this plan turns them into state.

Output: `read_event_tail` + `hook_status`/`last_tool`/`offset_events`/`notification_type` capture in `meta.rs`; `StateSource` enum + `status_with_source()` + `HOOK_FRESH_MS` + a new `mod tests` in `session.rs`.
</objective>
