<feature>
  <name>Gesture-time bare-URL detection and target validation</name>
  <files>baude/src/links.rs (implementation + `#[cfg(test)]` modules links::bare_url, links::validate)</files>
  <behavior>
    Bare-URL pass (parser bytes -> collect_links -> DetectedLink set):
    - "see https://example.com/path today" -> one link, destination https://example.com/path
    - URL wrapped at the column boundary across two rows (row_wrapped true) -> one joined link; spans cover both fragments
    - explicit newline mid-"URL" (row_wrapped false) -> NOT joined; each side validated independently (and the fragments fail validation or stand alone)
    - "(https://en.wikipedia.org/wiki/Foo_(bar))" -> trailing `)` stripped once (unbalanced), inner balanced paren retained -> destination ends in `(bar)`
    - "https://example.com/a.," -> trailing `.,` stripped
    - case-insensitive scheme match (HTTPS://, Http://) -> detected, normalized by parse
    - URL whose tail wraps past the bottom visible row -> joined via bounded continuation (<= 4 rows), anchor span on the visible fragment; a continuation chain longer than the bound yields the truncated candidate only if it still validates, else nothing
    - cells belonging to an OSC8 run containing "https://printed.example" as its label -> excluded from the bare pass (no duplicate entry)
    - screen with no URLs -> empty result (feeds 10-04's "no links visible" state)
    Validation matrix (validate_http_url):
    - accept: https://example.com, http://example.com:8080/a?b=c#d, https://ex.com/%E2%9C%93 (percent-encoded UTF-8 survives, normalized form returned), http://user@host/p
    - reject: file:///etc/passwd, javascript:alert(1), data:text/html;x, ftp://x, mailto:a@b
    - reject: raw control char in string (\x07, \x1b), raw whitespace ("https://a b"), tab/newline embedded
    - reject: percent-encoded controls %00, %0A, %1B (post-decode re-check)
    - reject: empty string, "https://", "http:/one-slash", not-a-url
    - property: for every accepted input, returned Url::as_str() contains no control chars and scheme is exactly http or https
  </behavior>
  <implementation>
    Logical-line builder: iterate visible rows (plus bounded continuation rows past
    the edge via the wrap flag), accumulate row text and (row, start_col, end_col)
    fragment spans, flush at each row where row_wrapped(row) is false (PATTERNS
    "Bare-URL wrap join" sketch, RESEARCH Pattern 4). Scan each logical line for
    case-insensitive scheme anchors, extend across the RFC 3986 charset
    (unreserved / gen-delims / sub-delims / %), then trim unbalanced trailing
    `.,;:!?)]}'"` iteratively (a `)` or `]` is kept when its matching opener occurs
    within the candidate). Map candidate byte-ranges back through the fragment spans
    to cell coordinates. Exclude cell ranges whose link_id() is Some (OSC8 wins).
    Gate every candidate through validate_http_url; store the parsed Url in
    DetectedLink. No screen mutation, no persistent state — pure function, called
    only at gesture time (locked decision).
  </implementation>
</feature>
