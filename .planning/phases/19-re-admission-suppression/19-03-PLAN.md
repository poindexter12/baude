<objective>
Add `marker::clear_owned`, the inverse of `write_marker`: release ownership of a managed repository directory by deleting its marker only when the marker is provably ours, then remove the now-empty directory non-recursively, and report refusals instead of guessing. Plan 04 calls this from the clearing stage with the directory derived from `SavedRepository::physical_key`.

Purpose: READM-02 says a removed repository's managed directory must no longer claim ownership so the next admission allocates afresh. A marker deleted for the wrong owner orphans another repository's worktrees (D-06, costly). The behaviour table (owned, foreign, invalid, symlink, missing, non-empty) is exactly the kind of input/output contract TDD is for, and it lives next to the existing marker tests.
Output: the `MarkerClear` result types and `clear_owned` in `marker.rs`, with six tests.
</objective>

<feature>
  <name>Owner-checked marker clear with non-recursive directory removal</name>
  <files>baude-core/src/marker.rs</files>
  <behavior>
    - Owned marker in an otherwise empty directory: `clear_owned(dir, owner)` returns `Ok(MarkerClear { marker: Removed, directory: Removed })`; afterwards `read_marker(dir)` is `Ok(Missing)` and `dir.exists()` is false
    - Marker written for different owner bytes: returns `Ok(MarkerClear { marker: Refused(ForeignOwner), directory: Untouched })`; the marker file bytes and the directory are unchanged
    - Malformed marker content: `marker == Refused(Invalid(Malformed(_)))`, `directory == Untouched`; a symlinked marker file: `marker == Refused(Invalid(Symlink))`, `directory == Untouched`, and the symlink target file still exists
    - `dir` does not exist: returns `Ok(MarkerClear { marker: Missing, directory: Missing })`
    - Owned marker plus a subdirectory: returns `Ok(MarkerClear { marker: Removed, directory: NotEmpty })`; the subdirectory still exists and the marker is gone
    - `dir` is a symlink to a directory holding an owned marker: returns `Ok(MarkerClear { marker: Refused(DirectoryIsSymlink), directory: Untouched })`; the target's marker and directory survive
    - No marker but an empty directory: returns `Ok(MarkerClear { marker: Missing, directory: Removed })`
  </behavior>
  <implementation>Check `std::fs::symlink_metadata(dir)` first: `NotFound` short-circuits to `{Missing, Missing}`, a symlink short-circuits to `{Refused(DirectoryIsSymlink), Untouched}`. Then `read_marker(dir)?`: `Missing` leaves `marker = Missing`; `Valid(meta)` with `meta.canonical_common_dir == owner_common_dir` does `std::fs::remove_file(dir.join(".baude-marker.json"))?` and sets `Removed`; any other `Valid` returns `ForeignOwner`; `Invalid(reason)` returns `Invalid(reason)`; refusals return early with `Untouched`. Finally `std::fs::remove_dir(dir)`: `Ok` is `Removed`, `ErrorKind::NotFound` is `Missing`, `ErrorKind::DirectoryNotEmpty` is `NotEmpty`, any other error propagates as `Err`.</implementation>
</feature>
