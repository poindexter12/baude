|----------|-------------|

| removed set → shared files | One removal writes to files shared by every repository and workspace on the machine |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-19-12 | Denial of service | clear_stage outcomes | medium | mitigate | Every marker refusal, directory-not-empty and I/O error maps to a `ClearingFailure`; `marker_refusal_and_non_empty_dir_are_reported_not_raised` proves `remove` returns Ok with the save committed (D-14) |
