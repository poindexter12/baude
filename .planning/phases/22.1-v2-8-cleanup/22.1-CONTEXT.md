<decisions>
## Implementation Decisions

### WR-06 locking
- Hold the manager lock only to re-check the preview and reserve the repository, and again to save and publish. The slow part, killing runtimes and deleting worktrees, runs outside the lock on a blocking thread. Other requests are served during that window; any request touching the repository being removed gets 503 Busy through the existing repository reservation. The save runs under the lock so a removal stays all-or-nothing (T-21-28), the reservation refuses a second removal of the same rows (T-21-14), and `rows_removed` is published only after the save returned (T-21-53). The 21-SECURITY.md entries for T-21-02, T-21-14, T-21-28 and T-21-53 must be re-pointed at the new evidence. — **Reversibility:** costly — three closed threat mitigations and their tests rest on this exclusion; changing it again means re-proving each.

### PWA polish
- Removal that deletes a folder is announced in the confirmation title only, for example "Remove this worktree and delete its folder?", driven by the preview report's `paths_deleted`. Row tags stay as they are.

### Decided autonomously
- [Suppression sync] Q: "One suppression store for TUI and daemon, or one each?" → Selected: "Keep one shared store; a removal or an explicit admission in either client applies to both; pin with cross-client tests and document in README" — today's behaviour made explicit; separate stores would let a PWA removal be undone by the TUI's next sweep.
- [Suppression sync] Q: "Where the lift key comes from" → Selected: "One baude-core function returning the repository root or the canonical path, called by both the TUI lift and the daemon lift, with a test pinning them together" — two call sites and one function.
- [Test hygiene] Q: "How the four PTY and signal tests stop leaving sleep 30 runtimes" → Selected: "A drop guard that kills and reaps the fixture process group, also on panic" — test-only code.
- [Test hygiene] Q: "How fixture temp directories get removed" → Selected: "A hand-written drop guard removing each fixture root; no new crate" — test-only code; a crate can be swapped in later.
- [PWA polish] Q: "Unclaimed sessions" → Selected: "Group under an 'other sessions' heading with no remove control, as Phase 21 intended" — rendering-only change in app.js.
