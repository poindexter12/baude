# Phase 22.1 Plan 05: baude crate runtime reaping and fixture roots Summary

The whole `baude` crate, 360 tests, now runs under `scripts/assert-no-test-leftovers.sh` with `command=0 orphans=0 live=0 dirs=0`. Every App test stops its runtimes through a reaper that sweeps the recorded session. Every fixture root in `app.rs`, `main.rs` and `ui.rs` is a `FixtureRoot`.

**Cause of the stray:** the gate shell runs `sh -c 'sleep 30'` as a job in a process group of its own. `App::kill_all` signals only each session's PTY leader. When the job outlives the leader, it is reparented to pid 1 but stays in the session the App recorded. It is a tracked runtime's child, not a runtime the App lost.

## Stop-rule decision

**Not triggered.** The decision rests on `target/gsd-22.1/05-compare.txt` alone.

The reproducing run was `05-before.log`, filter `app::tests::restore`, `before=1`, with every App instrumented: 93 `APP-RUNTIME` lines. The watcher recorded the strays from outside in `05-stray.txt`:

```
18:19:41 ps: 43479     1 43479 S    sleep 30 | sid=42520 | cwd=.../baude-admission-restore-launching-23565/repo
18:19:41 ps: 43498     1 43498 S    sleep 30 | sid=42640 | cwd=.../baude-admission-restore-launching-23565/data/baude/worktrees/restore-launching/repository-1/feature-restore-launching-2-3
```

The restarted App of that fixture listed, before its `kill_all`:

```
APP-RUNTIME id=1 role=agent pid=42520 pgid=42520 sid=42520
APP-RUNTIME id=2 role=agent pid=42640 pgid=42640 sid=42640
```

Both stray sids equal a listed sid, so neither stray is a runtime the App lost track of. No production code changed.

The watcher in the `05-before-app.log` run needed 31 s per pass and recorded nothing. It was narrowed to `sleep` processes for the later runs.

## What was built

- **`kill_all_and_reap(&mut App)`** builds `session_reapers` for every listed session, calls `App::kill_all`, then drops the reapers.
- **`session_reapers(&Session)`** returns a `RuntimeReaper::for_identity` for the agent and, when present, the shell.
- **Teardown:**
  - All 61 bare `kill_all` calls in app tests now go through `kill_all_and_reap`. That covers the suppression tests, the restore tests and fixtures, and every other App test.
  - Twelve mid-test kills now bind a reaper before they kill: `session_reapers`, or `RuntimeReaper::for_pty` for an agent-only kill. One example is the `claude.kill()` in `restarting_an_exited_session_restores_its_pane`.
- **Fixture roots in app.rs, all 30 sites:**
  - `admission_repo` owns `Option<FixtureRoot>`, declared last in `AdmissionRepo`.
  - `isolation_scope` holds `_root: FixtureRoot`, declared last; its `NEXT` counter is gone.
  - The worker-isolation and real-git-dogfood re-exec roots pass `root.path()` to the child.
  - Also converted: the hierarchy action state root, four standalone roots, folder context, held lock, seed warning, the 15 `baude-test-*` roots and the fixed `baude-test-gen`, `-marks` and `-idle2` names.
- **main.rs, 7 sites:**
  - `CliFixture` holds a `FixtureRoot`; its hand `Drop` and `NEXT_FIXTURE` are gone.
  - Six TUI loop tests create their launch dir through `FixtureRoot`.
- **ui.rs:** `UiFixture` holds its root as a `FixtureRoot` declared after both guards, so the root that was never removed is now removed.
- **Cleanup lines:**
  - 71 trailing or pre-assert `remove_dir_all` lines on fixture roots were deleted. The 8 that ran before asserts were checked first: none of those asserts reads the filesystem.
  - Mid-test removals that are part of a test's own steps stay: `collision`, `folder`, `fx.unmanaged`, `tmp1` and `tmp2`, and the `break_worktree` removals.
  - Root bindings left unused became `_root`. `StaleRestore` and `SavedWithStandalone` lost their `root` field.

## Deviations from Plan

1. **[Rule 1] The stray reproduced in the restore tests, not the suppression test.** The plan's escalation found it: single test, then `suppress`, then `app::tests::`. Task 1 therefore applied the helper to the restore tests and fixtures as well as the five suppression tests. Commit 7738f53.
2. **[Rule 3] The watcher was rebuilt.** Probing all 549 ppid-1 processes with `lsof` took 31 s per pass, longer than a stray lives. The rebuilt watcher probes only `sleep` processes every 0.5 s.
3. **Instrumentation went wider than the named test.** Following "instrumenting each test the run names", every saving and restarted App in the restore tests printed `APP-RUNTIME` lines, with an `APP-RUNTIME-CONTEXT` line naming the fixture, because Apps reuse session ids. The printer and its calls were removed before the Task 1 commit.
4. **[Rule 2] Every App test, not only the before-run's named ones.** The must-have truth says every App test that stops its runtimes reaps by session, so all 61 bare `kill_all` calls were replaced.
5. **[Rule 1] Mid-test kills got reapers.** Task 2's first after-run left an orphan from `restarting_an_exited_session_restores_its_pane`. The test kills the agent itself, the restart replaces that identity, and the final reap cannot see it. Twelve sites of that shape now bind a reaper before the kill. Commit b4e5870.
6. **Cleanup that ran on success only is now unconditional.** The worker-isolation parent removed its root only when the child succeeded. Its `FixtureRoot` now removes it always, so a failing run no longer leaves the root for inspection. No assertion changed.
7. **main.rs and ui.rs were edited while the Task 1 module run was in flight.** They stayed unstaged until the Task 3 commit. Every app.rs edit for Task 2 waited until `05-before-2.log` had finished.
