Conversion rules:
- `let root = std::env::temp_dir().join(format!("baude-x-{..}", pid)); remove_dir_all; create_dir_all` becomes `let root = crate::testing::FixtureRoot::new("baude-x");`. Keep the existing family prefix so leftovers stay attributable. `Deref<Target = Path>` keeps `root.join(..)` and `&root` working; add `.to_path_buf()` only where a `PathBuf` is required.
- A file fixture, such as a meta.rs JSON path, goes inside a `FixtureRoot` directory.
- A fixture struct with `root: PathBuf` and a hand `Drop` that only removes the root gets a `FixtureRoot` field declared after every field that must drop first, and loses the hand `Drop`. A hand `Drop` that also does other work keeps that work.
- A fixture that canonicalized its root, as `LifecycleFixture` does, keeps the `FixtureRoot` alive and canonicalizes the path it hands out; one that relied on the `/var` symlink, as `resume_fixture` in backend/claude.rs does, keeps the non-canonical path.
- A trailing `remove_dir_all(&root).unwrap()` at the end of a test is deleted, since the guard owns removal.
- No assertion, fixture shape, git command or redirect changes. Everything stays inside `mod tests` or the module's `#[cfg(test)]` items.
